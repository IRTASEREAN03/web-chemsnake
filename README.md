# ChemSnake

Website promosi untuk ChemSnake, board game ular tangga kimia dengan sistem 3 nyawa.

## Isi
- `index.html` halaman utama
- `style.css` tampilan
- `script.js` mini game interaktif
- `assets/poster.jpg` poster ChemSnake

## Hosting di GitHub Pages
1. Buat repository baru di GitHub, lalu upload semua isi folder ini (index.html harus berada di root).
2. Buka Settings > Pages.
3. Pada Source pilih "Deploy from a branch", branch `main`, folder `/ (root)`, lalu Save.
4. Situs aktif di `https://USERNAME.github.io/NAMA-REPO/` dalam beberapa menit.
